# BD Jomi Map — Prototype V3

BDLandPro-inspired, original land-measurement web prototype.

## V3 additions
- OpenStreetMap base map
- Satellite layer toggle
- GPS-to-point measurement
- Undo point
- Fit boundary to map
- Improved local-projection area calculation
- Decimal, square feet, katha, acre, perimeter
- KMZ export
- Saved projects and plot information

## GitHub Pages
Upload the files in this folder to a **new repository** (do not use the Truck-Driver-Trip repository). Enable GitHub Pages from `main` / root.

## Note
GPS and map measurements are field-measurement aids, not substitutes for official cadastral records or a government survey.
